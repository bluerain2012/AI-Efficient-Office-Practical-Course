# 《数据分析提示词流程》模板

> 目标：拿到任何表格（销售/财务/运营），都能照着下面 5 步跑完，产出**可落地**的清洗结果、分析结论和行动建议。
> 适用对象：门店销售、电商订单、项目台账、财务报表、用户行为表等二维数据。

---

## Step 0 · 先说明：标准输出格式

每跑完一步，默认产出：

| 输出物 | 格式 | 命名规则 |
|---|---|---|
| 体检报告 | Markdown | `步骤1_数据质量体检报告.md` |
| 清洗后数据 | Excel（多表：主表 + 异常 + 日志） | `步骤2_清洗后数据.xlsx` |
| 清洗日志 | Markdown | `步骤2_清洗日志.md` |
| 业务分析汇总表 | Excel | `步骤3_业务分析汇总表.xlsx` |
| 业务三问分析 | Markdown | `步骤3_业务三问分析.md` |
| 异常清单 | Excel | `步骤4_异常订单清单.xlsx` |
| 一页纸报告 | Markdown + 图表 PNG | `步骤5_一页纸经营分析报告.md` |
| 流程模板 | Markdown | `步骤6_数据分析提示词流程.md` |

## Step 1 · 数据质量体检

> 先不分析、不改动，只列问题清单。

### 必做检查清单

- [ ] **日期格式**：有几种写法？有没有非法日期（如 2 月 30 日）？
- [ ] **枚举字段归一**：门店、产品、品类、客户类型等，同一实体是否有多种写法？
- [ ] **完全重复行**：是否存在所有字段都相同的行？集中在哪些订单号？
- [ ] **缺失值**：哪些字段缺值？缺的是关键字段（金额/数量/日期）还是次要字段？
- [ ] **金额校验**：金额是否等于 单价 × 数量？不等的有多少？
- [ ] **异常值与测试数据**：单价是否 0.01、数量是否 999、金额是否为负、备注是否含“测试”？
- [ ] **对照标准表**：如果有价目表/产品表，单价是否都匹配？偏差的有多少？
- [ ] **格式污染**：是否有首尾空格、全角空格、特殊字符？

### 产出模板

```markdown
# 数据质量体检报告

## 一、总体
- 原始行数：__
- 关键字段完整率：__%
- 直接可用？（是 / 否，若否则列 3 个最大风险）

## 二、日期
| 日期格式 | 行数 | 样例 |
|---|---|---|
| ... | | |

- 非法日期：__ 行（列订单号 + 原始日期）
- 可修复日期：__ 行

## 三、枚举字段归一
### 门店 / 产品同义异名
| 应归一为 | 原始写法 | 行数 |
|---|---|---|
| ... | | |

## 四、重复与缺失
- 完全重复行：__ 组，__ 行
- 缺失行：__ 行（按字段列明细）

## 五、金额/单价异常
- 单价偏离标准价：__ 行
- 金额 ≠ 单价×数量：__ 行
- 测试/异常单：__ 行

## 六、三句话结论
1. 最影响统计的 3 个问题是：__、__、__。
2. 若直接汇总，销售额会偏差约 __ 元。
3. 清洗前必须先人工确认的 3 件事：__、__、__。
```

### 提示词示例

```text
请对上传的表格做一次数据质量体检，不要改数据。重点检查：
1. 日期格式有几种、有没有非法日期；
2. 门店/产品/品类等同店异名、同品异名；
3. 完全重复行；
4. 缺数量、金额等关键字段的行；
5. 对照价目表（标准表）检查单价可疑；
6. 异常值如单价0.01、数量999、金额负数、备注含测试。
请输出一份体检报告，按“问题/影响行数/示例订单号/建议”格式整理。
```

## Step 2 · 按规则清洗（每一步留痕）

### 清洗规则清单（可根据数据调整）

| # | 规则 | 处理方式 | 输出到哪 |
|---|---|---|---|
| 2.1 | 日期统一为 `YYYY-MM-DD` | 可修复的修正；无法修复的移入异常 | 主表 / 待确认-日期非法 |
| 2.2 | 门店/产品按标准表归一 | 建映射字典替换；未命中保留原值并标红 | 主表 / 清洗日志 |
| 2.3 | 去空格、去全角空格 | 所有文本字段 `trim` | 主表 |
| 2.4 | 完全重复行只保留一条 | 基于原始字段去重，删除第二行 | 已删除重复行表 |
| 2.5 | 金额为空但可算则补全 | 单价 × 数量 | 主表（补全说明） |
| 2.6 | 数量为空且可整除则补全 | 金额 ÷ 单价，能整除才补 | 主表（补全说明） |
| 2.7 | 金额对不上的行单独列出 | 不移入统计，人工核对 | 待确认-金额对不上 |
| 2.8 | 明显异常单不参与统计 | 备注含“测试” / 单价 0.01 / 数量 999 等 | 异常待确认 |

### 产出模板

- Excel：至少 4 个工作表
  - `清洗后主表`
  - `异常待确认`
  - `待确认-金额对不上`
  - `已删除的重复行`
  - `清洗日志`
- Markdown：`步骤2_清洗日志.md`（规则 + 处理行数 + 关键问题）

### 提示词示例

```text
请按以下规则清洗数据：
1. 日期统一为 YYYY-MM-DD，无法修复的单独列出；
2. 门店/产品按标准表归一；
3. 完全重复行只保留一条；
4. 金额为空按单价×数量补全，三者对不上的单独列出；
5. 备注含“测试”、单价0.01、数量999的移入“异常待确认”不参与统计；
6. 清洗日志要求：每条规则写清楚“处理了多少行、处理前示例、处理后状态”。
请输出 Excel（多工作表）+ 清洗日志 Markdown。
```

## Step 3 · 用“人话”连问三个业务问题

### 问题设计原则

每个问题必须包含：
1. **一张小汇总表**（3-8 行）
2. **一句结论**（不超过 30 字）
3. **支撑数字**（至少 2 个）

### 通用问题模板（销售场景）

| # | 问题 | 关键维度 | 注意点 |
|---|---|---|---|
| Q1 | 各门店销售额如何？哪家最强/最弱？为什么？ | 门店 × 月份 × 日均销售额 | 注意月份天数差异 |
| Q2 | 品类/单品谁贡献最大？Top 3 是谁？为什么？ | 品类 × 单品 × 销售额占比 | 关注爆品与长尾 |
| Q3 | 时间节奏/渠道结构如何？周末 vs 工作日？外卖 vs 到店？ | 星期 / 周末 / 渠道 | 注意工作日天数更多 |

### 产出模板

```markdown
## 问题 X：____？

### 汇总表
| ... | ... |

### 结论
**一句话结论：____。** 依据：____；____。

### 为什么
- 原因 1 + 数字；
- 原因 2 + 数字；
- 风险提示（若有）。
```

### 提示词示例

```text
基于清洗后的数据，用人话回答三个业务问题，每个问题都要：
① 一张小汇总表；
② 一句结论；
③ 支撑数字。
问题：
1. 四店 6 月 vs 7 月销售额如何？哪家最强、哪家下滑？为什么？
2. 咖啡/茶饮/烘焙哪个贡献最大？单品 TOP3 是谁？为什么？
3. 按星期几汇总，周末和工作日有何差别？外卖和到店占比如何？为什么？
```

## Step 4 · 让异常自己“现形”

### 异常清单字段

| 字段 | 说明 |
|---|---|
| 影响程度 | P0-极高 / P1-高 / P2-中 / P3-低 |
| 异常类型 | 重复、非法日期、金额对不上、退款、测试单、单价录错等 |
| 订单号 | 可追溯 |
| 涉及行号 | 原始文件中的行号 |
| 问题描述 | 人话说明哪里错了、影响多大 |
| 建议处理方式 | 删 / 改 / 补 / 回系统查 |
| 对销售额影响 | 估算金额或“影响归属” |

### 影响程度定义

| 级别 | 含义 | 处理优先级 |
|---|---|---|
| P0-极高 | 会让统计结果失真到不可用，必须先确认 | 立刻 |
| P1-高 | 明显影响某维度数字 | 24 小时内 |
| P2-中 | 单笔或结构性问题，影响可控 | 本周内 |
| P3-低 | 不影响金额，仅影响个别分析 | 有空处理 |

### 提示词示例

```text
在原始数据中整理一份异常订单清单，按影响程度排序。包含：
- 重复行、非法日期、金额与单价数量对不上、退款负数、测试单、单价疑似录错。
字段：影响程度、异常类型、订单号、问题描述、建议处理方式、对销售额影响。
最后告诉我哪些会显著影响统计结果。
```

## Step 5 · 一页纸报告

### 给老板看的结构（金字塔 + 数字）

```markdown
# X-X 月经营分析（一页纸）

## 一、核心结论（3 条，每条：一句话 + 1-2 个数字）
1. ____（依据：____）
2. ____（依据：____）
3. ____（依据：____）

## 二、关键数据与图表
- 核心指标表（销售额、订单数、客单价、环比）
- 分门店/分品类图表（柱状图/饼图/折线图，已生成或给 Excel 可复刻的图表建议）

## 三、异常与数据质量问题
| 异常类型 | 数量 | 影响 | 处理方式 |

## 四、可执行建议（2 条，每条：依据 + 具体动作 + 负责人/时间）
1. ____
2. ____
```

### 提示词示例

```text
基于清洗后的数据，写一页纸经营分析报告给老板看。
要求：
1. 3 条核心结论，每条一句话 + 支撑数字；
2. 分门店/分品类对比图表（直接生成图片或给图表建议）；
3. 列出异常与数据质量问题及清洗口径；
4. 2 条可执行建议（要有依据和具体动作）；
5. 风格直接、有数字、不堆术语。
```

## Step 6 · 沉淀《数据分析提示词流程》模板

> 把本次用到的规则、表格、提示词固化，下次拿到新表格直接复用。

### 沉淀内容

1. **数据字典**：本次字段含义、枚举值、标准表。
2. **归一映射表**：门店 / 产品 / 品类对应关系（作为新表加入 Excel）。
3. **异常规则清单**：哪些情况直接删、哪些补全、哪些待确认。
4. **业务三问模板**：针对该类数据最常问的三个问题。
5. **图表清单**：固定要出的图表类型与 Excel 复刻参数。
6. **提示词全文**：可直接复制给 AI 用。

### 沉淀文件

- `步骤6_数据分析提示词流程.md`（本文件）
- 可选：Excel 版《分析模板.xlsx》，含固定的工作表结构。

## 附：万能提示词（可直接复制给 AI）

```text
你是一位数据分析助手。我会上传一个数据表（可能是一张脏表）和一张标准表（如产品价目表）。
请严格按照下面 6 步执行，每步产出对应文件：

Step 1：数据质量体检（不改数据）
- 检查日期格式/非法日期、同店异名/同品异名、完全重复行、缺失值、
  金额≠单价×数量、单价偏离标准表、异常值/测试单、格式污染。
- 输出 Markdown 体检报告。

Step 2：按规则清洗并留痕
- 日期统一为 YYYY-MM-DD；门店/产品按标准表归一；去重；
- 金额/数量可推算的补全；三者对不上的、异常单单独列出。
- 输出 Excel（主表 + 异常 + 日志）+ 清洗日志 Markdown。

Step 3：业务三问
- 用“人话”回答 3 个业务问题，每问：小汇总表 + 一句结论 + 支撑数字。
- 输出 Markdown。

Step 4：异常清单
- 整理所有异常订单，字段：影响程度、异常类型、订单号、问题描述、
  建议处理方式、对销售额影响，并按影响程度排序。
- 输出 Excel。

Step 5：一页纸报告
- 给老板看的 3 条核心结论 + 图表 + 异常与口径 + 2 条可执行建议。
- 输出 Markdown，并直接生成或给出图表建议。

Step 6：沉淀提示词流程
- 把以上流程写成可复用的 Markdown 模板。

注意：
- 清洗前要告诉我处理了多少行、怎么处理的；
- 结论必须带具体数字；
- 发现影响统计结果的重大异常要单独标红。
```
