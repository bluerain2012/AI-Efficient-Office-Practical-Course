# 我的文件管理规则模板

> 制定日期：2026-08-16 ｜ 适用范围：本工作区（及同类「丢文件给我整理」的场景）
> 用法：以后你发来新文件 / 新发票 / 新合同，我直接按本模板处理，不再每次重新问方案。

---

## 总原则（三条铁律）
1. **只读优先、绝不主动删除**：整理只做复制或移动，删除/清空任何东西前必须先列清单等你确认。
2. **拿不准 → 进「待我确认」**：归类有疑问、疑似重复、无名空壳，一律放进待我确认，不臆测。
3. **重名自动加后缀保护**：同名文件归位时自动加 `_1`、`_2`，绝不覆盖你的原文件。

---

## ① 文件夹分类清单

根目录下建 `整理归档\`，固定 6 类 + 1 个缓冲：

| 文件夹 | 放什么 | 说明 |
|--------|--------|------|
| `合同证件\` | 合同、租赁、劳动、简历、身份证/银行卡照片 | 含 `敏感\` 子文件夹 |
| `合同证件\敏感\` | 身份证 / 银行卡 / 证件照片 | 个人敏感信息，单独隔离并提醒加密 |
| `财务票据\` | 发票、报销单、工资条、水单、高铁票、报销制度 | 按 `日期_类型_关键信息` 命名 |
| `工作文档\` | docx / xlsx(非空) / pptx、培训通知、需求、总结 | 版本堆叠只留最终版 |
| `图片截图\` | 微信/QQ/屏幕截图、手机照片 IMG_* | 证件类照片不进这里 |
| `安装程序\` | *.exe / *.msi / 安装包 | 可从官网重下，不必囤 |
| `其他\` | zip / mp4 / m4a / dat / 说明.md 等 | 兜底类别 |
| `待我确认\` | 所有拿不准 / 疑似重复 / 无名空壳 | ★ 缓冲，定期回看清理 |

---

## ② 命名规则

**通用格式：`日期_类型_关键信息.扩展名`**

- **日期**：能确定写 `YYYYMMDD`（如 `20260605`）；不确定统一写 `待补日期`。
- **发票**：`20260605_餐饮发票_欢聚楼` —— 日期_类型_销售方或场景。
- **合同**：`待补日期_服务合同_供应商` / `待补日期_租赁合同_房屋` —— 日期_合同类型_对方。
- **制度/说明**：`待补日期_报销制度_公司`。
- **避免**：`v2`/`终版`/`改`/`副本`/`重新下载`/`(1)` 这类临时版本词；避免空格和特殊字符。
- 重名处置：自动改为 `原名_1.扩展名`，不覆盖。

---

## ③ 新文件归位原则（标准步骤）

1. **扫描**：递归列出全部文件 + 大小 + MD5，输出分类统计。
2. **判空**：0 字节空文件单独标记，不做内容去重，先问是否占位/练习素材。
3. **分类**：先看文件名关键词（发票/报销/合同/身份证…），再看扩展名。
4. **去重**：
   - MD5 完全相同 → 留 1 份，其余进「待我确认」。
   - 文件名疑似版本/副本 → 留最终版，其余进「待我确认」。
5. **敏感隔离**：身份证 / 银行卡 / 证件照片 → 移入 `合同证件\敏感\`，并提醒加密、移出工作目录。
6. **归位**：按分类复制/移动到对应文件夹（默认保留可移回，不删原文件）。
7. **出清单**：生成本次操作说明，标注待你决策项。

## ④ 发票台账固定表头

新建 `报销台账.xlsx`，Sheet1「报销台账」固定 8 列（第 8 列为额外辅助列）：

| 列 | 字段 | 说明 |
|----|------|------|
| 1 | 序号 | 顺序编号 |
| 2 | 开票日期 | YYYY-MM-DD |
| 3 | 类型 | 餐饮/出行/住宿/铁路客票/办公用品/快递/会议… |
| 4 | 销售方 | 开票单位 |
| 5 | 发票号码 | 全号；小票填「—」 |
| 6 | 金额(元) | 数值，便于求和 |
| 7 | 用途备注 | 事由、人数、行程等 |
| 8 | 报销状态/风险提示 | ✅可报 / ⚠需补材料 / ❌不可报（对照制度） |

- 末尾加合计行：**合计（全部）** / **可报销** / **不可报销** 三行金额。
- Sheet2「报销制度核对」：逐条列出公司报销制度（如 §1 抬头要求、§2 时效、§3 餐饮标准、§6 审批等），标注每张发票命中情况。
- 颜色规则：✅ 绿、⚠ 黄、❌ 红。

---

## ⑤ 合同必须提取的字段清单

每份合同输出「信息卡 + 行动提醒清单」，必提取字段：

- **合同双方**：甲方 / 乙方（名称 + 联系人 / 电话 / 经办人）
- **期限**：起始 — 终止（精确到日）
- **金额与付款节点**：总额、分期比例/金额、每期付款截止日
- **违约条款**：逾期违约金比例、单方解除赔偿、没收押金等
- **需记住的时间节点**：到期日、付款日、通知截止日
- **★ 重点「不主动做就吃亏」条款**（必须单独标红）：
  - 自动续约（期满前 N 日未书面终止即自动续）
  - 提前通知义务（续租/解约须提前 X 日书面）
  - 押金退还条件（须主动腾退/验收）
  - 其他沉默即吃亏的默认条款
- **交付物**：两张信息卡 + 一张**按时间排序**的行动提醒清单（标注已过期的紧急项）
